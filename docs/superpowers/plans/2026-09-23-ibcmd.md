# Группа команд ibcmd — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Группа команд `ibcmd` для сборки/обновления ИБ 1С из исходников EDT и сопутствующих операций через утилиту ibcmd.

**Architecture:** Классы команд → модуль опций `РаботаIbcmd` → класс `МенеджерIbcmd` → `КонтролируемыйПроцесс` → ibcmd. Путь к ibcmd — через `v8find`.

**Tech Stack:** OneScript, cli, v8find, tempfiles, 1testrunner.

**Spec:** `docs/superpowers/specs/2026-09-23-ibcmd-design.md`

## Global Constraints

- Платформа 8.3.20+ и 8.5; используется путь `infobase config ...`.
- Маска версии по умолчанию — `8` (как у v8runner: последняя установленная).
- Без командной оболочки; пароли в логе и в JSON `--processpath` маскируются `***`.
- Новых зависимостей в `packagedef`/`Dockerfile` нет.
- `--dynamic`: `auto|disable|force`; `--sessionterminate`: `disable|force`.

## Уточнения по результатам экспериментов (2026-09-23, ibcmd 8.5.1.1423)

- `infobase config import --extension=X` создаёт отсутствующее расширение — отдельный `extension create` не нужен.
- Экспорт в непустой каталог ibcmd отклоняет — `configsavetoxml`/`extension savetosrc` очищают каталог (как `edt cli export`), это указано в справке.
- При ошибке ibcmd возвращает ненулевой код.
- `v8find` для масок `8.3*` возвращает пусто, если в установке 8.3 нет компонента ibcmd → понятная ошибка.
- Тесты с платформой включаются по наличию ibcmd (и EDT для `build`), а не по имени компьютера.
- `КонтролируемыйПроцесс` пишет полную строку запуска в лог отладки и в JSON `--processpath` → добавляется представление строки запуска.
- Каталог данных создаётся лениво при первом вызове ibcmd.

## Review Focus

- Пароль со спецсимволами (`&`, пробел, `"`) — передаётся без искажений и не виден в выводе.
- Пути с пробелами (`C:\Program Files\...`) у ibcmd и у аргументов.
- Непустой каталог в `configsavetoxml` — очищается, а не падает.
- `--user "null"` из CI-шаблонов — трактуется как пустой пользователь.
- Ошибка ibcmd — код выхода 1 и временный каталог данных удалён.
